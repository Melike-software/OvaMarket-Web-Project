# Ova Market - Web Otomasyonu Projesi

Ova Market, modern ve kullanıcı dostu bir e-ticaret web otomasyonu projesidir. Bu proje kapsamında yönetim paneli ve müşteri arayüzü entegre bir şekilde geliştirilmiştir.

## Kullanılan Teknolojiler
* **Backend:** Servlet, JSP (JavaServer Pages)
* **Veritabanı:** MySQL
* **Frontend:** Bootstrap 5, HTML5, CSS3, JSTL
* **Sunucu:** Apache Tomcat v9.0
* **IDE:** Eclipse
  
## Proje İçeriği ve Özellikleri
* **Müşteri Modülü:** Ürün arama, sepete ekleme, sepeti güncelleme ve başarılı sipariş oluşturma adımları eksiksiz çalışmaktadır.
* **Yönetici Modülü:** Ürün yönetimi, kategori ekleme ve sistem kontrolleri mevcuttur.
* **MVC Mimarisi:** Projede Java Servlet'leri Controller, DAO yapıları veritabanı iletişimi, JSP sayfaları ise view katmanı olarak kurgulanmıştır.

##  Kurulum ve Çalıştırma
1. Projenin ana dizininde bulunan ovamarket_db.sql dosyasını MySQL Workbench üzerinden içe aktarın.
2. Projeyi Eclipse IDE'sine aktarıp Apache Tomcat (v8.5/v9.0/v10.0) sunucusu ile ayağa kaldırın.
3. Tarayıcıdan veya eclipse run as server'a giderek sistemi test edebilirsiniz.
